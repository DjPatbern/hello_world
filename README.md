# Overview

This project is a simple Hello World web application built with JavaScript. It displays a greeting on a webpage and also prints the message to the browser console.

The purpose of creating this software is to practice the basics of JavaScript, learn how JavaScript interacts with an HTML page, and establish a starting point for building more interactive web applications.

[Software Demo Video](https://youtu.be/IHwn_YZI_Ww)

# Development Environment

- **Tools:** Visual Studio Code (or another code editor), a web browser, and the browser developer console.
- **Language:** JavaScript, with HTML used to structure the webpage.
